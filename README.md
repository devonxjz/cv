# Trần Lê Thái - Portfolio

A recruiter-focused portfolio for a backend engineer, AI engineer and security-minded developer. Built with Next.js, Tailwind CSS, Motion and GSAP.

## Local development

```bash
pnpm dev
```

Open `http://localhost:3000`.

## Production checks

```bash
pnpm lint
pnpm build
```

## Personal details

Contact and social links live in the `profile` object at the top of `app/page.tsx`.

The downloadable resume is served from `public/tran-le-thai-cv.pdf`. Its reproducible source is `scripts/generate_resume.py`.
